# Upskill Dashboard App

This repository contains a simple static dashboard app for a 3-month French and SAP upskilling plan.

## What it includes

- A dashboard with overall progress, tasks, and deadlines
- Two separate skill tracks: French and SAP
- Daily lesson content with real source recommendations
- 10-minute quizzes and weekly 30-minute exam workflows
- Weakness analysis and review guidance
- A simple study bot for answering questions

## Run locally

1. Open `index.html` in your browser.
2. Use the dashboard to track your daily plan and launch quizzes.
3. Ask the bot questions in the chat section.

## Color style
- Baby pink, white, and purple theme
- Soft, minimal, and motivation-focused layout

## Sources referenced
- French: *Practice Makes Perfect: Complete French Grammar*, *Easy French Step-by-Step*, TV5Monde, Duolingo, FluentU
- SAP: *Discover SAP*, *SAP ERP Financials: Configuration and Design*, openSAP, SAP Help Portal, SAP Community
